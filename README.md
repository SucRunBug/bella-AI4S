# bella-AI4S

跨学科科研 Skill，按课题和已有材料衔接选题、文献、研究设计、实验复现、数据分析、论文返修、科研图表与汇报。

## 能力

- **按需执行**：35 行主入口，八份参考按任务加载，小编辑直接处理。
- **科研导航**：发现遗漏与逻辑缺口，说明影响、最小补救和可继续的工作。
- **场景记忆**：每轮检查必要增量，按场景调用习惯、项目决定与实践经验；支持纠正、归档与遗忘。
- **科研可视化**：区分数据图、结构／机制图、实验影像和汇报，检查科学含义与最终文件编辑能力。
- **证据与复现**：保留来源定位、真实运行记录、结论边界和失败结果。

## 使用

将本仓库内容放入宿主的 `bella-ai4s` Skill 目录，保留 `references/`、`scripts/` 和 `agents/`。也可以直接要求具备本地文件能力的助手读取 [SKILL.md](SKILL.md)，无需安装。

```text
使用 $bella-ai4s。我的课题是……，已有……，本轮需要……。
请复用相关记忆，提醒关键科研缺口，完成任务并保存必要进展。
```

## 目录

```text
SKILL.md        入口与路由
references/     文献、方法、分析、写作、可视化、证据、记忆、导航
scripts/        项目初始化、证据登记检查、场景记忆工具
agents/         宿主显示信息
```

三个辅助脚本仅使用 Python 标准库，需要 Python 3.9 或更新版本。核心指令不依赖特定付费 API。

## 记忆与执行边界

记忆默认保存在当前项目 `.bella-ai4s/memory.json`，不写入 Skill 目录。跨项目复用习惯需明确指定共享存储；项目记录仍按项目路径隔离。详见 [记忆规则](references/memory.md)。

助手负责提取与判断，脚本负责匹配、校验、原子写入和版本冲突检测。Skill 生效时每轮检查增量，无新增信息不写入；没有配置后台钩子，不能保证所有宿主每段对话自动触发。无可写存储时应明确未保存。

证据脚本只检查登记结构和本地文件，不能验证科学结论。专业软件、联网检索、算力与文件导出依赖实际宿主能力。

版本：1.1.0。发布前 35 项脚本行为测试通过；尚未完成真实科研全周期或所有宿主的自动触发实测。
