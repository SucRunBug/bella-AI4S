# 科研导航

首次进入复杂课题或阶段明显改变时，用一句话说明当前阶段、已有产物和关键缺口；小编辑不展示全流程。状态从文件与执行记录判断，不凭印象给百分比。

| 环节 | 检查 |
|---|---|
| 选题 | 问题是否可回答，已有工作是否已解决，最小验证是否可行 |
| 文献 | 阅读范围是否支持细节判断，是否遗漏竞争解释或反对证据 |
| 设计 | 研究单位、对照、目标估计量／指标、前提与资源是否明确 |
| 执行／分析 | 数据泄漏、依赖结构、方案变更、选择性汇报、未运行的结果 |
| 推断 | 相关与因果、未显著与无效、仿真与证明、局部结果与泛化 |
| 写作 | 贡献、方法、证据、摘要及结论是否对应 |
| 图表／返修 | 数值与语义一致，编辑能力真实，回复中的修改确已完成 |

提醒按「具体问题 → 对本轮的影响 → 最小补救 → 可继续的部分」组织，优先提出最关键的一项，不泛称“不够严谨”。
- 影响有效性：暂停依赖该问题的结论／执行，继续独立工作。
- 限制范围：标明局限，缩小结论后继续。
- 可选改进：简短建议，不阻塞。

按学科调整检查；探索阶段缺少最终结果是正常状态。能从材料核对或在授权内修复就直接做，需要用户事实或关键选择才询问。已答过的背景复用记忆，解决后关闭提醒；历史错误只在当前条件匹配时检查。
阶段结束说明产物、真实检查、尚缺什么与一个优先下一步。不自动扩展任务。复杂依赖才用阶段图／证据对应图，见 [图表与汇报](communication.md)。
