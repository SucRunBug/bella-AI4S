# 科研可视化与汇报

## 路由与输入

先确定科学问题、已有材料、受众、输出用途和编辑需求；复用相关视觉记忆，不重复提问。只生成帮助理解或交付所需的图，简单状态用文字。

| 类型 | 产物与检查 |
|---|---|
| 数据图 | 输入引用、绘图代码、导出图、图注；核对单位、研究单位、分组、数值与不确定性 |
| 流程／架构 | 节点、标签、连线、分组和编辑源文件；核对语义与关系方向 |
| 机制／概念 | 关系依据、可调整组件、布局；区分观察、解释与假设 |
| 实验影像 | 原始影像、处理日志、标尺与面板对应；不生成或重绘研究证据 |
| 汇报／海报 | 讲述主线、图表与备注、源文件；按受众和最终尺寸检查 |
| 科研导航 | 阶段、依赖或贡献—证据对应；状态来自实际产物和检查记录 |

## 数据图

1. 检查变量字典、单位、分组、缺失／零／删失、重复结构及结果版本。分析方法按 [分析与推断](analysis.md) 处理。
2. 每图先明确一个主要问题，再按分布、关系、时间、空间或比较选图型。必要时显示原始观察和不确定性，避免只展示均值。
3. 记录筛选、聚合、归一化、平滑和分箱。误差条注明定义、独立 n 与研究单位；说明截轴、对数及零／负值处理。
4. 先生成一版可核对草图，再优化排版。图、表、摘要数字复用同一结果源；数据变化时重跑并核对受影响的下游内容。
5. 保留图记录：目的、输入、处理、代码、图注、输出、检查状态。无真实数据只做标注清楚的示意图。

投稿或分享的科学图优先使用可复跑绘图工具和独立文件。交互适用于筛选、缩放、比较和探索；交互状态应可重置，筛选条件可见，并保留静态导出所需的数据和设置。

## 结构与机制图

先列对象、标签、箭头含义、方向、分组和证据，再布置位置。相关、因果、流程和假设不能使用未解释的同一种连线。图片重绘先提取语义清单，对照原图检查漏项、误字和错连；不清楚的关系标待核对。
用稳定对象标识保存结构与样式；局部修改只改相关对象。复杂机制可组合生成的概念组件，但必须核对结构，不能把生成图用于证明实验观察。

## 编辑能力与交付

| 层级 | 验收 |
|---|---|
| 数据可更新 | 修改输入后能重新运行生成 |
| 对象可编辑 | 文字、节点、连线等能独立选择与修改 |
| 组件可调整 | 组件可移动缩放，内部可能仍是位图 |
| 整页图片 | 只能整体替换或裁剪 |

根据最终文件实际检查并说明能力。SVG 含位图、PPTX 含整页图片、导出图内嵌源文件，都不代表其显示对象可直接编辑。用户要求 PPT 内部对象可编辑时需检查最终 PPT 对象结构。
交付编辑源格式与导出文件；字体转轮廓能保留外观但不保留文字编辑能力。缺工具时交真实源格式和未执行说明。

## 汇报与视觉记忆

论文按最终尺寸和目标规范组织信息；组会突出本轮发现、问题与下一步；答辩提供关键证据和必要备份页；海报支持远距离与快速阅读。
每页确定一个讲述目标，避免整段搬论文。频繁改稿优先可编辑对象；公式密集可用 LaTeX Beamer 并交源码。保留图表来源、证据编号、关键假设和讲稿。
按 [记忆规则](memory.md) 保存用户明确选择的语言、配色、字体、面板、图注及编辑偏好。未获采纳的样例观察先为 candidate。处理组／变量名称、颜色和符号保持跨图一致；项目配色不自动全局应用，投稿要求优先于不兼容的习惯。

## 检查与成本

科学内容与呈现分别验收。先核对数值、单位、关系与图注，再实际渲染检查文字大小、截断、重叠、字体、图例、面板和颜色辨识；颜色配合符号或线型，不能是唯一提示。
投稿时查确切期刊、文章／图类型、提交阶段的当前官方要求；不把一个 DPI、栏宽或配色当通用认证。导出后检查实际尺寸、格式、字体与栅格部分。
流程为内容确定 → 草图 → 定向修改 → 检查。优先复用代码与样式，不默认生成多套风格；反复修改须带来明确改善并受预算约束。
导航状态使用未开始／进行中／已完成／待核验／受阻；产物已生成与证据已核验分开，不造完成百分比。只在依赖复杂时画图，提醒内容按 [科研导航](navigation.md)。
