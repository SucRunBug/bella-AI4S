# 科研图件架构与投稿契约

按需读取：规划多面板图、重排已有图、投稿前 QA、AI 示意图时读本文件；其余只读 [communication.md](communication.md)。

## 1 多面板证据架构

### 1.1 从 figure-level claim 开始

画图前先写（不直接按数据/指标数量排面板）：

```text
Results 级问题：
图级结论（一句话，含动词）：
什么能推翻它：
决定性证据：
panel 序列：a — 问题 | 证据角色 | 必要比较
去向：主图 | 另一图 | 附录/补充材料
```

一张 Figure 回答一个 Results 级科学问题的默认原则。panel 可在"为确立、限定或界定同一高层结论"时承载多个从属发现；某 panel 支撑独立主结论就单独成图。panel 删除后不改变图级推断 → 合并、降级到附录或删除。

### 1.2 panel 证据角色（选最小充分集，不是每张图都要全）

| 角色 | 回答的问题 |
|---|---|
| 设置/示意图 | 测试的是什么系统、干预或对照 |
| 代表性示例 | 现象在具体案例中长什么样 |
| 主定量证据 | 核心效应/能力是否存在 |
| 基线/对照 | 是否超过可信替代方案、通过相关对照 |
| 分解 | 哪些组分/变量解释该效应 |
| 分层 | 结论在科学上有意义的条件内是否成立 |
| 正交验证 | 用另一测定/指标是否复现结论 |
| 扰动/压力测试 | 破坏必要关系时 claim 是否如预期失败 |
| 边界/失败案例 | 效应在哪里减弱、反转或停止泛化 |
| 机制证据 | 支持效应为何发生的有界解释 |

panel 相互**必要**而非独立故事。角色多样性优先于指标多样性：`a: R², b: R² 两两比较, c: MAPE, d: MAPE 两两比较` 只是两个推理角色换指标，不构成四块证据。更强布局：`a: 扰动设计 → b: 决定性比较 → c: 完整分布/残差 → d: 分解或边界`。

### 1.3 证据链原型（选一个，只保留 claim 需要的动作）

- **验证包络**：系统/能力是否可信 → 定义能力 → 建立 → 测不同失败模式 → 攻击 claim → 界定边界。一致性、泄漏、安全性、偏差、对抗鲁棒性同属"同一可信度 claim 的不同失败方式"，可放一张图，不当作无关指标面板。
- **尺度到实例**：群体规律需要生物/临床/物理解释 → 全局分布 → 定量 → 空间关系/尺度 → 内部结构 → 代表性例外。代表性示例要解释、定位或挑战聚合模式，不是装饰性轶事。
- **发现序列**：每个结果改变下一个问题 → 假设 → 决定性实验 → 分析 → 修正假设 → 下一步检验 → 机制验证。只保留改变 claim 或推动下一步的步骤，不复制实验记录本。
- **能力阶梯**：方法论文的逐步更强声明 → 是什么 → 学到了什么行为 → 是否超越替代 → 更苛刻条件下是否仍成立 → 更广能力。下一张图问更深的问题，不重画同一排行榜。

可复用链路：`建立 → 比较/对照 → 压力测试/判别 → 扩展 → 界定`。

### 1.4 主图 vs 附录/补充材料（必要性三问）

1. 删掉此 panel，哪个独特推断消失？
2. 该推断是确立、推进、限定还是界定图级结论？
3. 是独立证据角色，还是同一结果换指标/估计器/seed/阈值/编码？

- **主图**：决定性证据、必要对照、核心证伪、改变结论的边界。
- **附录/补充**：安抚性证据、来源细节、次要指标、替代估计器、扩展子组、不改变中心解释的稳健性。
- **另一图**：真正独立的主结论或 claim escalation 的下一级。
- **删除/合并**：无独立推断增益的重复视图。负面/复杂结果若改变结论，不得因难看而隐藏。

### 1.5 跨图 claim escalation

图序应让每张图提出前一张图创造的问题：`图1 是什么 → 图2 评价/资源是否可信 → 图3 现象是否存在 → 图4 是否优于替代 → 图5 更苛刻条件下是否成立 → 图6 机制/泛化/边界`。两张图都能概括为"X 表现好"时，合并、降级较弱证据，或把后图改造成更深判别器。

|---|---|---|---|---|---|---|
| a |  |  |  |  |  |  |

整图审计：图级结论能否一句话陈述？panel 是否共同回答一个 Results 级问题？每 panel 是否只加了新指标/图型？顺序是否构成可读链条而非仪表盘？最强证据是否视觉主导？核心对照/攻击/失败边界是否在场？挪到附录是否会削弱主结论？下一张图是否问出本图创造的问题？图注能否不重放全文而讲清"显示什么、怎么读"？

## 2 投前 QA 契约

### 2.1 检查清单（逐项勾选，Fail/Pass/豁免+理由）

| 检查 | 通过条件 |
|---|---|
| 核心结论 | 一句话 claim 存在，每个 panel 映射到它 |
| 证据角色 | 有声明 archetype 与 panel 层级 |
| 后端独占 | 选定的 Python/R 后端完成全部绘图、预览、导出与 QA 渲染 |
| 最终尺寸 | 单栏约 89 mm 或双栏约 183 mm，高度不超期刊上限 |
| 字号 | 正文/刻度/图例在最终尺寸可读，密集图通常 5–7 pt |
| panel 标签 | 小写粗体、左上角、最终尺寸约 8 pt |
| 可编辑文本 | SVG/PDF 文字可选中编辑，特殊符号除外 |
| 字体 | 统一无衬线（Arial/Helvetica 或回退） |
| 颜色 | 无彩虹色图；红绿不是唯一编码；灰度打印仍可读 |
| 图例策略 | 尽量共享/直接标注，不重复冗余图例 |
| 统计 | n 定义、生物/技术重复、中心统计量、离散度、检验、校正、精确比较均已记录 |
| 可比不确定性 | 每个可比的种子/折/分割聚合 panel 用同一离散度定义，或记录豁免 |
| 注释避让 | 自动碰撞审计无 FAIL；每个 WARN 在最终尺寸复核并记录理由 |
| panel 对齐 | 可比的同行/同列边界、尺寸、标签锚点、重复间距对齐（默认 1.5 pt），或记录豁免 |
| 视觉层级 | 渲染后主证据比中性基线更显著 |
| 数值变换 | 插值/归一化方向与单调性假设在代码中声明 |
| 源数据 | 定量 panel 可追溯到干净 CSV/TSV/XLSX 或脚本输出 |
| 栅格分辨率 | 照片/显微图分辨率满足最终尺寸；线图尽量矢量 |
| 显微标尺 | 标尺存在、已校准，不只用放大倍数 |
| 图像完整性 | 裁剪、对比度、伪彩色、拼接、复用、原始文件来源均已记录 |
| 交付包 | 脚本、源数据、SVG、PDF、TIFF/PNG 预览、QA 记录一并交付；预览不冒充投稿格式 |

### 2.2 统计 legend 最小字段（每个定量 panel）

```text
n 定义：       生物重复 / 技术重复 / 独立单元
中心统计量：   均值 / 中位数 / 原始
离散度：       SD / SE / CI / 无（说明理由）
检验：         方法 + 多重比较校正
p 值表述：     精确值 / 区间 / 星号约定
源数据文件：
```

机器学习/模型图另加：train/validation/test 划分、seeds/folds 数、指标定义、CI 或离散度定义、baseline 定义。

### 2.3 图像完整性最小字段（每个图像 panel）

```text
原始文件：  处理文件：  裁剪：  亮度/对比度/gamma：
伪彩色：    标尺校准：  拼接：  是否复用于其他图：
定量关联：
```

全局调整通常比局部选择性编辑安全。调整改变了相关背景/条带可见性时标记，不静默归一化掉。

### 2.4 自动化预检

交付/返修前运行（无依赖、确定性）：

```bash
python3 <skill目录>/scripts/audit_figure.py 绘图脚本.py            # 源码静态预检
python3 <skill目录>/scripts/audit_figure.py 绘图脚本.py --strict   # WARN 阻断
```

结果只说明源码层面的已知风险模式，不证明图或分析正确；所有 WARN 在最终尺寸复核，QA 记录写明理由。面板对齐与渲染碰撞仍需实际渲染后人工/几何核验。

## 3 期刊与导出契约

默认值服务于 Nature 系风格的保守起点，**不替代目标期刊官网当前要求**；投稿前查确切期刊、文章/图类型与提交阶段。

| 项 | 默认起点 |
|---|---|
| 单栏/双栏 | ~89 mm / ~183 mm |
| 正文/刻度/图例字号 | 5–7 pt（最终尺寸） |
| panel 标签 | 小写粗体 ~8 pt |
| 旗舰 Nature 图注 | 整图 <250 英文词（官网最新为准） |
| Nature 系初投稿 vs 终稿 | 初投稿可宽松；终稿执行严格尺寸/DPI/source data |
| 栅格导出 | ≥300 dpi（终稿常 600） |
| 字体可编辑 | matplotlib `svg.fonttype="none"`、`pdf.fonttype=42`；R 用 svglite/cairo_pdf |
| source data | 定量 panel 可追溯文件 |

多面板对齐默认容差 1.5 pt（约 0.53 mm）；故意不等宽/异形需 panel 级豁免并写明科学理由，不为掩盖一个例外放宽全局容差。

## 4 视觉基线

- 颜色：优先可感知均匀色图（viridis 类）；类别色用色盲安全调色板；同一条件/队列/方法映射跨 panel 一致。顺序浅→深色图不冒充无关类别色。
- 文字：无衬线统一字体；非 ASCII 特殊符号优先 Unicode（如 R²），避免 mathtext 缩小到 5 pt 以下。
- 布局：panel 标签固定点偏移自轴角；标签位置从数据与误差上限推导（`max(center+spread)+margin`），不用固定 LABEL_Y。
- 层级：主证据面积/位置主导，对照与稳健性 panel 安静但可判读；不强制等大。
- 旋转文字用 `rotation_mode="anchor"`；曲线穿过标签时把标签移到局部数据包络之外，不用白底框挖洞。

## 5 AI 示意图与图形摘要

- AI 生成只做**草稿**，不当作定量数据 panel、实验观察或可投稿终稿；输出附"需人工重画/核实元素"清单。
- 先定义：单一中心信息、图件类型、目标读者、证据边界，再构图与配色。
- 优先本地模型/本地绘图能力，不默认调用外部生成 API；需外部服务时先取得用户明确授权。
- 投稿前单独核验目标期刊最新 AI 政策、科学准确性、版权、披露与 provenance；从业者经验文章不是投稿许可。
- 不虚构实验数值、机构标识、未支持机制；机制图必须与证据对应，区分观察、解释与假设。
